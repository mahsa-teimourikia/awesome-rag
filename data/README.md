# Learning data

`data/enterprise/` contains the fictional NovaTech corpus used by the Enterprise notebook track. It is deliberately small and inspectable: documents, metadata, incidents, deployments, and runbooks are fixtures for learning retrieval and operations—not production data.

The broader evaluation questions live in [`datasets/enterprise_questions.json`](../datasets/enterprise_questions.json). Add a question and expected evidence there when an experiment needs a regression case.
