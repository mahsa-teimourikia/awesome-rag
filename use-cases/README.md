# Use-case catalog

Use cases are project-based paths that apply the same retrieval foundations to different data, risk, and evaluation requirements.

| Level | Use case | First pattern to implement |
| --- | --- | --- |
| Beginner | Documentation assistant | Hybrid-ready metadata and citations |
| Beginner | Personal notes assistant | Local ingestion and abstention |
| Intermediate | Customer support | Query rewriting, reranking, escalation |
| Intermediate | Legal or policy research | Section-aware chunks, provenance, strict ACLs |
| Intermediate | Codebase assistant | Symbol-aware chunks, lexical search, file/line citations |
| Intermediate | Research synthesis | Multi-query retrieval, deduplication, claim citations |
| Advanced | Enterprise knowledge assistant | Tenant isolation, audit trails, freshness |
| Advanced | GraphRAG investigator | Entity linking and relationship retrieval |
| Advanced | Agentic RAG | Routing, tools, corrective loops, human approval |

Each use case should eventually have a problem statement, architecture diagram, fixture data, threat model, runnable implementation, evaluation set, limitations, and extension exercises.
