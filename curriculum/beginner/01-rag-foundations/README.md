# 01 — RAG foundations

**Level:** Beginner  \
**Time:** 20 minutes  \
**Prerequisites:** basic Python and command-line usage

## Learning objectives

You will be able to:

- Explain the difference between a model's parametric knowledge and retrieved evidence.
- Name the ingestion, chunking, indexing, retrieval, generation, and evaluation stages.
- Explain why retrieval quality and answer faithfulness must be evaluated separately.
- Recognize abstention as a useful behavior when evidence is missing.

Read [What is RAG?](../../../docs/what-is-rag.md), then inspect the two files in [`examples/data/beginner-docs`](../../../examples/data/beginner-docs).

## Checkpoint

Before continuing, draw the pipeline from memory and label one failure mode for each stage. Compare your result with the [RAG architecture diagram](../../../assets/rag-pipeline.svg).
