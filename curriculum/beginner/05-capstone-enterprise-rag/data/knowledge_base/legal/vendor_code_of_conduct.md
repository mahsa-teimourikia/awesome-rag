# Vendor Code of Conduct
Effective Date: 2024-06-01
Version: 2.0
Status: Active

## 1. Introduction
Northstar Technologies requires all third-party vendors, suppliers, and contractors to adhere to this Code of Conduct.

## 2. Security Requirements
Vendors processing Northstar customer data must:
- Hold a valid SOC 2 Type II certification.
- Conduct annual penetration tests and share the summary report with Northstar Procurement.
- Encrypt all Northstar data at rest using AES-256 and in transit using TLS 1.3.

## 3. Incident Reporting
If a vendor experiences a data breach that potentially exposes Northstar data, the vendor must notify Northstar Security (`security@northstar.example.com`) within 24 hours of discovery. 

Failure to notify Northstar within the 24-hour window is considered a material breach of contract and may result in immediate termination of the vendor agreement.
