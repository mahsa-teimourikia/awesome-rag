# Employee Hardware Provisioning
Effective Date: 2026-02-01
Version: 3.0
Status: Active

## 1. Standard Issue Equipment
Upon joining, all full-time employees are provided:
- Apple MacBook Pro 14" (M3 Pro, 16GB RAM, 512GB SSD)
- Dell 27" 4K USB-C Monitor
- Northstar branded backpack

## 2. Engineering Exceptions
Employees in the Engineering or Data Science departments may request an upgraded machine:
- Apple MacBook Pro 16" (M3 Max, 64GB RAM, 1TB SSD)
This upgrade is pre-approved and simply needs to be selected in the IT portal during onboarding.

## 3. Hardware Refresh Cycle
Laptops are refreshed every 3 years. When an employee receives a new laptop, they must return their old laptop to IT within 14 days. 
Employees are absolutely prohibited from keeping old laptops for personal use due to security and MDM policies.

## 4. Lost or Stolen Devices
If a company device is lost or stolen, the employee must report it to IT via the urgent Slack channel (`#it-urgent-help`) within 1 hour so the device can be remotely locked and wiped via JAMF.
