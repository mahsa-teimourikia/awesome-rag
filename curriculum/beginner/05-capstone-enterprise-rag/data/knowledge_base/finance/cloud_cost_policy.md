# Cloud Infrastructure Cost Policy
**Effective Date**: Jan 1, 2025
**Department**: Finance & Engineering

## Resource Provisioning
Any new cloud resource projected to cost more than $500/month must be approved by a Tier 2 Engineering Manager and the Finance Cloud Operations team.

## Idle Resources
Any environment running without active connections for 14 days will be automatically suspended by the Cost Reaper bot.
