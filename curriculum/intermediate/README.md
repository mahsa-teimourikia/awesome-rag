# Intermediate path

**Outcome:** explain and improve retrieval quality using measurable experiments.

| Step | Lesson | What you learn |
| --- | --- | --- |
| 1 | BM25 and dense retrieval | Exact-match and semantic search trade-offs |
| 2 | Hybrid retrieval | Combine lexical and vector signals |
| 3 | Filters and permissions | Enforce metadata and access boundaries before retrieval |
| 4 | Rewriting and reranking | Improve recall and ordering for difficult queries |
| 5 | Evaluation lab | Build a golden set and diagnose retrieval versus answer failures |

Prerequisites: complete the beginner path and be comfortable reading basic evaluation metrics.

Begin with [retrieval strategies](01-retrieval-strategies/README.md), then continue with [metadata permissions](02-metadata-permissions/README.md), [query rewriting and reranking](03-query-reranking/README.md), the [evaluation lab](04-evaluation/README.md), [research synthesis](05-research-synthesis/README.md), and the optional [local Qdrant lab](06-qdrant-local/README.md).

Use [retrieval patterns](../../docs/retrieval-patterns.md) as the cross-lesson
design reference, [technology decisions](../../docs/technology-decisions.md) to
compare tools, and [evaluation](../../docs/evaluation.md) when interpreting an
experiment or release gate. Each row above links to its practical notebook.
