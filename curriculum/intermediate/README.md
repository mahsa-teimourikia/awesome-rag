# Intermediate path

**Outcome:** explain and improve retrieval quality using measurable experiments.

| Step | Lesson | What you learn |
| --- | --- | --- |
| 1 | BM25 and dense retrieval | Exact-match and semantic search trade-offs |
| 2 | Hybrid retrieval | Combine lexical and vector signals |
| 3 | Filters and permissions | Enforce metadata and access boundaries before retrieval |
| 4 | Rewriting and reranking | Improve recall and ordering for difficult queries |
| 5 | Evaluation lab | Build a golden set and diagnose retrieval versus answer failures |

Prerequisites: complete the beginner path and be comfortable reading basic evaluation metrics.

Begin with [retrieval strategies](01-retrieval-strategies/README.md), then continue with filters, reranking, rewriting, and evaluation.
