# Advanced path

**Outcome:** design a reliable, secure, observable RAG system for complex or high-impact use cases.

| Step | Lesson | What you learn |
| --- | --- | --- |
| 1 | Corrective and adaptive RAG | Detect weak retrieval and recover deliberately |
| 2 | GraphRAG and entity retrieval | Answer relationship-heavy and corpus-level questions |
| 3 | Agentic RAG | Route, plan, use tools, and preserve state safely |
| 4 | Multimodal and structured data | Combine text, tables, images, and SQL sources |
| 5 | Adaptive RAG | Build an LLM Router for pre-retrieval query classification |
| 6 | Production RAG | Freshness, observability, security, cost, and rollback |

Prerequisites: complete the intermediate path and understand access control, evaluation, and service operations.

Begin with [corrective and adaptive RAG](01-corrective-rag/README.md), then continue with [GraphRAG](02-graphrag/README.md), [agentic RAG](03-agentic-rag/README.md), [structured and multimodal RAG](04-structured-multimodal/README.md), and [production operations](05-production-operations/README.md).

Use the Adaptive RAG guide alongside corrective
and agentic lessons, the evaluation guide for
release decisions, and technology decisions
when selecting a production stack. Every advanced lesson links to an adjacent,
runnable notebook.
