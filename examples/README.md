# Reusable Python examples

The examples are small, deterministic implementations used by the curriculum. They are intentionally provider-free so a learner can inspect behavior before introducing a model SDK or hosted vector store.

Use the [course map](../COURSE_MAP.md) to find the example paired with a lesson. The examples are organized by level; the notebooks are the teaching surface and these modules are the reusable implementation surface.

Run from the repository root with `PYTHONPATH=.` and inspect the corresponding test in [`tests/`](../tests/).
