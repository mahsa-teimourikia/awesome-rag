# Learning path

Start with a small, inspectable lexical baseline before adding embeddings. Change one variable at a time and measure the effect on a fixed question set.

The next step is dense retrieval with Sentence Transformers and a vector store such as Qdrant. After that, compare hybrid retrieval, metadata filters, and reranking.

Every production system should preserve source identifiers, document versions, and section locations so answers can show traceable citations.
